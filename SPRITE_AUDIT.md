# Pocketmals sprite audit — November 2026

## What the current renderer does

- The game contains 65 species in `data.js`.
- 56 species have an explicit species-specific drawing branch in `drawCreaturePixelArt()`.
- 9 species do not yet have a dedicated body/silhouette drawing branch:
  - Brackibud
  - Puglow
  - Glacub
  - Hauntide
  - Duskrowl
  - Ferrivine
  - Drakindle
  - Dunemole
  - Faefern
- All nine now have a named idle-motion profile, but motion alone does not create their missing species artwork. Do not treat these as finished sprites.
- The current renderer draws procedural pixel art on a 48 × 48 canvas using a 24 × 24 logical grid. It is not yet a complete exported sprite-sheet pipeline.
- Front and back views are currently generated by one renderer. The back view has a separate marking pass, but it still needs a proper species-by-species art review.
- Human sprite assets are declared as an empty registry, so the game currently falls back to procedural character drawings. Professor Lotus has a dedicated procedural design and now uses a research/notebook idle animation.

## Animation improvements in this update

- Added small timed idle accents based on each Pocketmal's type: embers, bubbles, sparks, leaves, glints, wing highlights, status lights, dust and antenna details.
- Added named movement profiles for the nine species listed above so their intended movement styles are documented in code.
- Kept these animation accents separate from the base silhouette so they can be replaced by approved hand-drawn frames later.

## Original six reference drawings

The six drawings supplied by the owner in an earlier conversation are required visual references. Their actual image files and exact handwritten names are not available in this repository or the accessible project library at the time of this audit. Do not claim that any sprite has been verified against those six drawings, and do not replace those designs with generic procedural creatures.

When the owner re-adds the six reference images:
1. Save unchanged copies under `assets/reference-creatures/`.
2. Confirm each handwritten species name with the owner if it is not clearly readable.
3. Compare the existing sprite with the matching drawing at native size.
4. Fix the silhouette first, then face, markings, palette and small details.
5. Produce matched front and back battle views plus four-direction overworld views.
6. Add frame-by-frame idle and action animations without changing the approved design.

## Male/female variants

Only create separate male and female artwork when the approved species design has an actual visible difference. Do not add random colour swaps or stereotyped accessories to every species. Species with no confirmed visual distinction should share the same sprite art.

## Resolution and visual QA

The Black and White sprite archive shows that native sprite dimensions vary by species and pose. Pocketmals should therefore use per-species canvas bounds and integer scaling rather than forcing every finished sprite into one universal square. Use the archive as a pixel-art and animation reference only; do not copy its game sprites into Pocketmals.

Before calling the sprite set complete, check:
- silhouette readability at native game scale;
- transparent padding and consistent baseline;
- clean nearest-neighbour scaling;
- front/back anatomy consistency;
- all four overworld directions;
- idle, movement, attack, hurt and faint animations;
- shiny palettes that preserve the approved design;
- no blank species or missing animation frames.
